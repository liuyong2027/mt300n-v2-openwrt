# Release 20 — 普通版与诊断版

本轮分别构建 production 和 diagnostic，两者使用相同的代理后台、R3 补丁和运行保护。新普通版内核尚待编译核验和实机验证，自动正式发布暂停。

| 项目 | 普通版 production | 诊断版 diagnostic |
| --- | --- | --- |
| KALLSYMS / STACKTRACE / IKCONFIG / IKCONFIG_PROC | 关闭 | 保留 |
| DEBUG_INFO | NONE；关闭 DWARF 选择项 | 保留工具链默认 DWARF |
| MAGIC_SYSRQ | 保留救援入口 | 保留救援入口 |
| PROC_FS / PROC_STRIPPED | 保留 / 不裁剪 | 保留 / 不裁剪 |
| perf / ftrace / profiling / BTF | 关闭 | 关闭 |
| 临时采样、故障注入、实验启动钩子 | 不安装、不自动启动 | 不安装、不自动启动；按需外部采样 |
| 匹配的电脑端符号文件 | 单独保存，无 DWARF 行号数据 | 单独保存，含 DWARF |

保留 120 秒预检预算、子进程回收、回滚、恢复防火墙保护、锁和一致性检查，以及 BusyBox、MIPS 和容量验证。正常启动/应用耗时和探测状态记录继续保留。

页面删除订阅提示、剩余流量和套餐到期三项显示；订阅解析仍过滤这类非节点数据。

2026-10-03 路由器只读审计未发现临时诊断启动钩子、活动采样器或升级保留清单中的相关残留。源代码内的测试和诊断工具不等于固件安装内容，编译后还会扫描实际 rootfs。

当前路由器代理测速仍约 5 Mbps；之前 12 Mbps 来自另一 Wi-Fi，已撤回该性能证据。间歇性切换慢的原因尚未完全定位，不承诺本轮精简提升吞吐。

详见 KERNEL-PROFILES-20.md。构建产物与 SHA256SUMS、验证记录、匹配的离线符号分开保存。
