# Release 20 — GL-MT300N-V2

正式版版本标识为 `20`，发布标签 `v20.0.0`。以 2026-10-03 已实测的 `20-rc2-loadingdiag` 源码为基线，保留相同代理运行代码、R3 核心补丁和内核配置，重新构建正式固件。

## 下载与安装

在仓库 [Releases](https://github.com/liuyong2027/mt300n-v2-openwrt/releases) 下载 `mt300n-v2-20-sysupgrade.bin`，核对同页 `SHA256SUMS`。源码包、符号文件不是刷机文件。发布工作流只有在构建、回归、实际 MIPS 配置、目标 BusyBox、内核配置和容量检查通过后才发布 BIN。

首次使用默认 LAN 为 `192.168.8.1/24`，时区 Asia/Shanghai；Wi-Fi 沿用 OpenWrt 默认名称，已开启且无密码。保留配置升级沿用原有设置。保留现有 ZeroTier 网关与 SOCKS5 功能及其防火墙配置。

## 功能与改进

- 直连、大陆分流、GFW 分流和全局代理；VLESS/REALITY/Vision、VMess、SS 节点和订阅。
- 有序备用节点、连通探测、WAN 故障判断和恢复冷却，减少故障时反复应用。
- 预检单实例与成功快照复用、同模式防火墙复用、失败回滚、恢复阻断保护；完整预检保留 120 秒执行预算，核心软内存限制保持 48 MiB。
- 中国 IP 配对更新与中断恢复、规则更新状态区分、轻量进度读取；状态分行和网站测试结束提示。
- R3 的 Vision UDP/443 提前拒绝补丁，保留此前实机验证结果。

## 已知限制与验证范围

偶发完整预检/正式启动慢、切换后代理短暂不可达仍未彻底定位。10 月 3 日同节点切换曾耗时 183 秒；后续空闲缓存命中的两次切换分别为 37 秒、18 秒。后两次更快不代表问题已经修复。预检执行预算不是整个应用流程的总时限。

用户确认这台路由器的代理下载仍约 5 Mbps，未观察到吞吐提升；不承诺固定代理速度。此次没有新增提高吞吐的核心算法。

新正式 BIN 不重复实机刷写验收；依据相同运行源码及内核配置的既有实机结果，结合本次全套构建检查发布。详见 `HARDWARE-EVIDENCE-20.json`、`RELEASE-20.md` 和发布资产中的 `BUILD-VERIFICATION.json`。历史文档保留用于追溯，其中旧版本、“未编译”等字样不代表本次构建状态。

## 构建

固定 OpenWrt 25.12.5 / commit `f0a60eee2fe051741c643ea6118718aae1ef17fb`，Xray 26.3.27 + R3；标准配置、1 MiB/XZ SquashFS。保留当前实测内核的 KALLSYMS、任务栈、IKCONFIG 与完整 proc，用于后续诊断；不启用 perf/ftrace/BTF。离线调试符号单独保留为 Actions 构建附件，不刷入路由器。

仓库的 `release20-source.zip.b64` 是源码 ZIP 的无换行 Base64；`.github/workflows/release20.yml` 校验并解包后构建。发布所附源码包包含完整文件清单和校验值。
