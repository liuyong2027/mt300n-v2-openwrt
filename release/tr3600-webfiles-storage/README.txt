TR3600 WebFiles 升级目录权限修复

基线：已发布 rc2，5fd9e9641aeb2b5415ecd3516c6add0c39f1c6af。
本分支为下一版完整固件准备源码修复，不替换 rc2 固件或标签。

修复：保留配置升级后，若 root 所有的私有目录被重建为 755，先验证固定公开标记和全部文件身份，再仅将目录恢复为 700。遇到可写目录、符号链接、非 root 文件、非 600 私有文件或硬链接时拒绝操作。账号密钥、账号密文与证书密文不读取、不更换。
启动路径：首次启动脚本在启用服务前执行；服务启动时在 reset 前再次执行。目录缺失时不创建，已有 700 目录不改变。保持原有私有目录检查。
验证：实际路由器原生 Lua/nixio 11 项通过；GitHub CI 使用发布 rc2 中的 ARM64 Lua/nixio，在独立的合成文件目录重放 11 项测试，包含实际 tar 文件清单恢复。CI 不代表新完整固件已刷机或手机端已验收。
不修改：网络速率、PHY、Xray、ZeroTier、DDNS、公网开关、账号密码、证书或 USB 数据。WAN 反复断链尚未定位，此修复不宣称解决 WAN 问题。
