# Cudy TR3600 V1.0 定制固件 1.0.0

本项目的正式发布版，基于 OpenWrt 25.12.5。仅适用于 **Cudy TR3600 V1.0**，不是 Cudy 原厂固件，也不适用于本仓库的 GL-MT300N-V2。

## 功能与修正

- 保留原代理界面、分流和自动切换、ZeroTier。
- 增加 SS 服务端及 LuCI 管理，支持 AES-128-GCM、AES-256-GCM、ChaCha20-Poly1305、TCP/UDP；仅限明确授权的私有 ZeroTier 接口和网段，默认关闭，无预置密码或个人网络 ID。
- USB 新盘首次在“网络共享 → USB 文件共享”授权；记住 UUID 后再插入自动恢复，自动重建共享元数据，提供只读/读写、安全卸载和取消授权。不格式化磁盘。
- Wi-Fi 双频合一纳入“无线”标签页；保留无线中继和频段引导。
- 增加状态 LED 推荐方案；LAN 和无关 USB 拔插不重置出口/代理状态。保留 WAN/LAN EEE 修正与 PPPoE 支持。
- 相对 RC1，修正 SS 防火墙守护无谓占用代理操作锁，以及 SS 关闭时页面仍显示勾选的问题。
- 移除 L2TP/IPsec 服务端和动态 DNS。

## 验证结果

完整 CI、原应用和双槽、实际 ARM64 Xray 14 项配置、SS 三种加密、UCI/nixio、9 项守护锁回归、真实 nft 隔离网络测试及最终镜像/压缩页面检查通过。

1.0.0 已完成保留配置升级和一次独立重启：11 项配置保持一致，代理、ZeroTier、SS、双频 Wi-Fi 与原 USB 自动恢复；SS 对端国内外访问均正常，白灯恢复常亮。实际 SMB3.1.1 的读写、中文名、目录、改名、删除和 ADS 元数据检查通过；90 个静态安装路径与源码或 ROM 比对通过。用户另确认 iPhone“文件”读写正常。

仍未全部覆盖长期稳定性、物理故障/夜间/升级灯光、可写 NTFS 及客户端占用磁盘时的安全卸载。

## 安装

先核对底部型号与硬件版本、备份配置并校验 SHA256。已有本项目匹配的 RC1/1.0.0 可从 LuCI“系统 → 备份/升级”上传本次 sysupgrade 镜像；本次已验收保留配置升级。原厂迁移须遵循 Cudy 官方中间固件流程，不能把 sysupgrade 直接当作原厂升级包。升级期间保持供电，不使用强制刷写。

原厂界面、App、云管理和原厂 Mesh 不保留。SS 未开放公网，USB 共享仅局域网。ZeroTier 重连后的 SS 自动恢复可能需要数分钟。
