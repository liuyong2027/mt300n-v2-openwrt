Cudy TR3600 V1.0 / R126 - 1.1.0-rc1

Candidate scope: integrate Cudy webpage WebFiles and standard LuCI DDNS.
PPTP and L2TP/IPsec server are not included. Preserve the1.0.0 base source,
its locked OpenWrt/feeds, USB consent, proxy/ZeroTier/SS, Wi-Fi and LED gates.

WebFiles0.6.2 uses the tested0.6.1-boot1 application with clean firmware
defaults: no personal USB fallback, port8080, disabled/read-only initially.
Preserve encrypted account.key/accounts and LAN/public/domain TLS slots across
a keep-settings upgrade. Stop deleting owner DDNS configuration at first boot.
Quantum is source rebuilt from the pinned v2.0.0-stable commit with the same
cryptographic128-bit JWT jti correction and unique-token regression test.
Default minimum webpage password remains6 characters; LuCI HTTP account saves
remain supported. A30-day local test CA is created on the owner's device.

Prior hardware evidence belongs to the old1.0.0 firmware plus separately
installed WebFiles0.6.1. It is not acceptance of this newly built image.
CI validates source, target programs, package selection, image contents and
metadata. Flashing and real-client checks of this image remain pending.
The known WAN short link flaps and FAT32 dirty warning are not claimed fixed.

The build may publish a GitHub Prerelease only after all verification jobs
pass and uploaded asset hashes match. It never writes to a router.
Only use a verified matching-device sysupgrade image; keep a backup and the
previous firmware before testing. See README.txt for custom versus stock paths.


ZeroTier direct-path fixes from the 2026-10-16 diagnostic are integrated:
- Pin secondary/tertiary UDP ports on a fresh installation; use the actual
  configured primary port. Preserve an existing local.conf without rewriting it.
- Accept only these UDP ports in fw4 input_wan; SSDP replies only from the
  current WAN default gateway, UDP source1900 to high ports. No private gateway,
  personal network ID, node identity or public mapping port is baked in.
- Reconcile this helper's owned nft chain after firewall reload, WAN changes,
  and ZeroTier start/stop. No proxy restart, timer loop or global firewall flush.
- Preserve /etc/zerotier-stable-ports.json in subsequent settings upgrades.
  IMPORTANT for the FIRST upgrade from older firmware: the old firmware selects
  backup paths. Before flashing, add /etc/zerotier-stable-ports.json and
  /etc/cudy-webfiles/ to its /etc/sysupgrade.conf, and verify they are in the
  backup archive. This build does not modify or flash the running router.
- Keep existing owner firewall rules. Low-bandwidth mode is not enabled.
  The optional small-ping trial on6.1 was not made permanent. This firmware
  does not claim to remove remote signature-verification delays or ensure
  DIRECT under all NAT/firewall conditions. New-image hardware testing pending.
