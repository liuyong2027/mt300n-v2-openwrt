# TR3600 v1 双频合一

下一版新增“网络 → 双频合一”中文配置页，默认关闭。启用前先在“无线”页面设置国家并启用两个局域网 AP，再选择 2.4 GHz / 5 GHz 接入点、共同无线名称及加密方式。密码留空时沿用所选 5 GHz 接入点的有效密码，也可设置新的 8–63 位密码。

启用后两频使用相同名称、密码及加密方式；可单独开关频段引导。应用会使无线短暂重连。关闭双频合一会恢复首次启用前两个 AP 的名称、密码、安全设置和原 usteer 配置；合一期间调整共同设置不会覆盖最初备份。

频段引导采用固定 feeds 中的 usteer 2025-10-04 / 1d6524c6e6b58853f053c7816249a8f68ad9b0e8，配合完整 wpad-mbedtls 及 802.11k/v。引导服务只在本机运行，并限制到共同 SSID；信号足够时向支持的终端发送切换至 5 GHz 的建议，最终选择由终端决定。未开启关联拒绝、负载踢出或弱信号强制踢出策略。访客和中继接口不会被配置引擎修改，共同 SSID 不得与其他 AP 重名。

原无线备份 /etc/cudy-wifi-backup.json 为 root 私有文件（0600），只保存恢复所需选项。程序以锁串行处理更改，先备份再修改；应用或配置提交失败时尝试恢复操作前状态。保留设置升级时保留管理配置与原备份。备份无法读取、接口不匹配、无线未启用、密码无效或组件缺失时拒绝修改。

源码检查覆盖默认关闭、同步、关闭恢复、模拟重启重复应用、访客/中继隔离、密码/SSID、备份及提交/服务失败恢复。实机频段引导和新镜像验收仍须在下一版固件编译完成后进行；当前在用固件未安装或启用本功能。
